# Cyclone Game STM32

A simple embedded Cyclone timing game built with STM32CubeIDE for the
STM32F091RC Nucleo board.

The game drives a row of seven LEDs. One LED moves back and forth across the
row, and the player presses the board push button when the lit LED reaches the
center position. Landing on the center LED triggers the win animation; stopping
anywhere else triggers the lose state.

## Hardware

- Board: `NUCLEO-F091RC`
- IDE/toolchain: `STM32CubeIDE`
- Programmer/debugger: onboard ST-LINK
- Other: Breadboard, Jumper wires, x7 100 Ohm Resistors, 7 LED's

## Gameplay

1. Press the user button to start the game.
2. The active LED moves across the seven-LED row.
3. Press the user button when the active LED is on the center LED.
4. If the center LED is selected, all LEDs play a blinking win pattern.
5. If any other LED is selected, the game waits for another button press and
  then resets.

## Pin Mapping

| Function           | STM32 Pin | Notes                                    |
| ------------------ | --------- | ---------------------------------------- |
| LED 1              | `PA0`     | Output                                   |
| LED 2              | `PA1`     | Output                                   |
| LED 3              | `PA4`     | Output                                   |
| LED 4 / Center LED | `PA5`     | Output, Nucleo LD2 pin                   |
| LED 5              | `PB4`     | Output                                   |
| LED 6              | `PB5`     | Output                                   |
| LED 7              | `PB3`     | Output                                   |
| Player button      | `PC13`    | Falling-edge interrupt, Nucleo B1 button |


Connect each external LED through a resistor.

## Project Structure

- `CycloneGame.ioc` - STM32CubeMX/CubeIDE configuration file.
- `Core/Src/main.c` - game state machine, GPIO setup, LED control, and button
interrupt handling.
- `Core/Inc/main.h` - generated board pin definitions and HAL includes.
- `Drivers/` - STM32 HAL and CMSIS driver files generated by CubeIDE.
- `STM32F091RCTX_FLASH.ld` - linker script for the target MCU.

## Building and Flashing

1. Install STM32CubeIDE.
2. Clone this repository.
3. Open STM32CubeIDE and choose `File > Import`.
4. Select `Existing Projects into Workspace`.
5. Browse to the cloned repository folder and import the `CycloneGame` project.
6. Build the project with `Project > Build Project`.
7. Connect the `NUCLEO-F091RC` board over USB.
8. Flash/debug with `Run > Debug` or `Run > Run`.

## Configuration Notes

- The system clock is configured for 48 MHz.
- The game uses HAL GPIO APIs and the `EXTI4_15` interrupt for the `PC13`
button.
- LED movement delay is controlled by `MOVE_DELAY_MS` in `Core/Src/main.c`.
- Button debounce delay is controlled by `DEBOUNCE_MS` in `Core/Src/main.c`.
